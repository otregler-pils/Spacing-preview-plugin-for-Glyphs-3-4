# Changelog

All notable changes to Spacing Preview are documented here.

## [1.1.0] — 2026-09-23

### Added
- Sixth spacing string: `HHxHnxnn`
- Stylistic set support: spacing glyphs follow the features active in the Edit view (`n` → `n.ss01`)

### Changed
- New low-contrast themes: dark (96.5 % black background, 90 % white glyphs) and light (96.5 % white background, 90 % black glyphs); dark stays the default
- Theme button now reads Dark/Light instead of Black/White
- Cleaner panel: transparent title bar, flat buttons in theme colours next to the window buttons; the panel can be dragged by its background
- The panel opens in the top-left corner of the Edit view
- Smaller default panel size

## [1.0.0] — 2026-09-04

Initial public release.

- Live preview of the selected glyph
- Five spacing strings
- Kerning on/off toggle
- Black/white preview theme
- Automatic visibility based on the active Glyphs Edit view
- Glyphs 3 and Glyphs 4 compatibility
