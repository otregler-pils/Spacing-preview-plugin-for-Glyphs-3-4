# Changelog

All notable changes to Spacing Preview are documented here.

## [1.0.0] — 2026-09-04

Initial public release.

- Live preview of the selected glyph
- Five spacing strings
- Kerning on/off toggle
- Black/white preview theme
- Automatic visibility based on the active Glyphs Edit view
- Glyphs 3 and Glyphs 4 compatibility
